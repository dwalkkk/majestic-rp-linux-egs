# Majestic RP на Linux (Epic/EGS GTA V) — воспроизводимая настройка

> **Внимание:** этот репозиторий не является официальным продуктом Majestic Role Play, Rockstar Games, Epic Games или их аффилированных лиц. Все торговые марки принадлежат их владельцам. Репозиторий содержит только документацию, скрипты проверки состояния и исходники छोटых утилит. Бинарники игр и лаунчеров не распространяются.

## Что внутри

- `docs/final-state.md` — описание итогового состояния системы, при котором игра запускалась.
- `docs/timeline.md` — хронология ошибок и попыток их решения.
- `docs/log-excerpts/` — очищенные фрагменты логов (без секретов).
- `scripts/check-state.sh` — скрипт проверки итогового состояния (не меняет ничего).
- `config/majestic-runner.conf` — пример конфига раннера с замаскированными путями.

## Быстрое воспроизведение

1. Установите Heroic Games Launcher, GE-Proton (latest), majestic-linux-runner-git (AUR).
2. Добавьте GTA V (Epic Games Store) в Heroic.
3. Настройте префикс и переменные окружения согласно `docs/final-state.md`.
4. Запустите `scripts/check-state.sh` для проверки состояния.
5. Запустите игру через Heroic (Play), затем нажмите «Играть» в Majestic Launcher.
